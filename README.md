# EZ Auto Clicker API

This is the API for EZAC, also known as, Easy Auto Clicker/EZ Auto Clicker, which contains vital files for the Injector.
This API contains the latest injector version and Minecraft target version for the injector.

This project wil be open source soon on the main project [EZ-Auto-Clicker](https://github.com/Shardzzexe/EZ-Auto-Clicker)

There's nothing much else to say but if you want to check this out just check out the README on the main project [EZ-Auto-Clicker](https://github.com/Shardzzexe/EZ-Auto-Clicker)
